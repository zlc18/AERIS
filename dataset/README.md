# Raw data

The raw data are not redistributed. Download the three datasets below from the
Elia Open Data Platform (tab *Export*, format JSON) for the period
2025-01-01 00:00 to 2025-12-31 23:45, Brussels time, and save them here under
the file names given.

| File | Dataset | Records |
| --- | --- | --- |
| `ods031.json` | Wind power production estimation and forecast, https://opendata.elia.be/explore/dataset/ods031/ | 175,200 |
| `ods032.json` | Photovoltaic power production estimation and forecast, https://opendata.elia.be/explore/dataset/ods032/ | 490,560 |
| `ods134.json` | Imbalance prices per quarter-hour, https://opendata.elia.be/explore/dataset/ods134/ | 35,040 |

The record counts let you check that a download is complete. Use of the data is
subject to Elia's terms of use.
